# *Combretum oyemense* Exell

**Genus**: [[Combretum]]
**Family**: [[Combretaceae]]
**Protologue**: Bull. Soc. Linn. Normandie 8-9 : 135 (1937) ; KEAY, FWTA, ed. 2, 1(1) : 272 (1954) ; LIBEN, Fl. Cam.: 25 : 60 (1983). TYPE : Gabon, Oyem (fl.) Le Testu 9315 (holo-P ; iso-BM, BR)

## Description

KEAY, FWTA, ed. 2, 1(1) : 272 (1954) ; LIBEN, Fl. Cam.: 25 : 60 (1983). TYPE : Gabon, Oyem (fl.) Le Testu 9315 (holo-P ; iso-BM, BR).

Liane ≤ 40 m and diameter ≤ 11 cm.

Leaves opposite ; petiole ≤ 12 mm ; blade obovoid-elliptic, ≤ 16 × ≤ 6 cm, papyraceous to coriaceous, glabrous or nearly so, somewhat shiny ; major lateral veins 5–8 pairs, domatia pubescent ; base of blade attenuate ; apex acuminate glandular.

Scales, diameter 70 μm.

Inflorescences ≤ 10 cm : spikes axillary or terminal ; bracts inconspicuous.

Flowers 4-merous, sessile, fragrant. Receptacle yellow and white : the lower, height 1–2 mm, the upper campanulate, width 4 mm, height 3 mm. Calyx, lobes deltoid. Petals subcircular, length 1–1.5 mm, glabrous or with a few hairs at the apex. Stamens exsert 5–6 mm ; anthers length 0.9 mm. Disk bearing white hairs. Style exsert 3–4 mm.

Fruit, circular in profile, length ≤ 3 and width ≤ 4.5 cm, wings finely coriaceous ; stipe 12–4 mm.

## Distribution

from Sierra Leone to Cameroon and Gabon

## Ecology

Dense humid forests, altitude ≤ 700 m
