# *Homalium dewevrei* De Wild. & T. Durand

**Genus**: [[Homalium]]
**Family**: [[Flacourtiaceae]]
**Protologue**: BJBB 38 (2) : 126 (1899) ; GILG, EBJ 40 : 489 (1908) ; SLEUMER, BJBB 43 : 267 (1973) ; (avec la collab. de BAMPS), FCBR, Flacourt. 2 : 12 (1976). TYPE : Dewèvre 861, Zaïre (holo-)

## Description

BJBB 38 (2) : 126 (1899) ; GILG, EBJ 40 : 489 (1908) ; SLEUMER, BJBB 43 : 267 (1973) ; (with collaboration from BAMPS), FCBR, Flacourt. 2 : 12 (1976). TYPE : Dewèvre 861, Zaire (holo-).

– H. myrianthum GILG, in ENGL., PWA 3 (2) : 579, in clavi (1921) ; MILDBR., Ergebn. Deutsch. Zentr.-Afr. Exp. 1910-1911, 2 : 60 (1922). TYPES : Mildbread 4480, Cameroon (lecto-, B, delet. ; P!, selected here ; isolecto-, HBG) ; 5780, Cameroon (syn-, B, delet., HBG).

- H. gnyenziense PELLEGR., Mém. Soc. Bot. Fr.: 118 (1952). TYPE : Le Testu 8303, Gabon (holo-, P! ; iso-, BM, K, P!).

– H. angustistipulatum KEAY, Kew Bull.: 80 (1953); in HUTCH. & DALZIEL, FWTA, ed. 2, 1 (1): 196 (1957). TYPE: Fishlock 12, Ghana (holo-, K).

Tree (8–15–(20) m tall) or shrub ; branchlets glabrescent.

Leaves with linear stipules, 3–5 mm long, often caducous ; petiole 5–10 mm long ; blade oblong, ovate-oblong or elliptic, cuneate to rounded at the base, shortly acuminate at the apex, (8)–12–22 × (3.5)–5–7–(9) cm, crenulate to subentire, chartaceous to subcoriaceous, puberulent along the veins ; secondary veins 9–10–(12) pairs.

Inflorescences in axillary and terminal panicles, much-branched, pubescent. Flowers 5–6–(7)-merous, grouped 2–3 together in fascicles along the rachis ; pedicel very slender, 0.5–1 mm long ; calyx with tube very slightly ribbed, 2.5 mm long ; lobes linear, 1.5–2 mm long ; petals obovate-oblong, 4 × 2 mm, accrescent to (5)–6–8 × 2.5–3 mm, ciliate. - Pl. 23, 1-3, p. 73.
